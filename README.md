# Vriksha Constructions & Interior Designers

Architectural, engineering, and interior design practice crafting enduring bespoke residences, commercial landmarks, and refined interiors.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS & Vanilla CSS Design System
- **Icons**: Lucide React
- **Animations**: CSS ScrollReveal & Custom Keyframes

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production Build

```bash
npm run build
npm run start
```
